# Changelog

## 0.4.0 — Public portfolio release and explicit hospital import

- Published both editions for public inspection, with a synthetic dashboard preview and an engineering case study.
- Added an explicit local export adapter for mapped columns and separate date/time fields, preserving source IDs and validating UTC offsets against local time.
- Added checked release downloads, synthetic examples and checksums after successful Linux and Windows CI.
- Kept real local records and credentials out of release artifacts; retained pending reuse licensing.


## 0.3.0 — Hospital and advanced development editions

- Added a copyable hospital runner with RStudio Source support, Windows launcher, editable local settings and offline dependency checks.
- Extracted one reporting pipeline shared by hospital and development entry points; added edition, package versions and software fingerprints to run receipts.
- Hospital execution requires an Excel workbook and blocks experimental significance testing.
- Added separate demographic-strata analysis and rolling-origin evaluation of two simple next-day forecast baselines; no prospective clinical scores.
- Added deterministic release packaging with file allowlists, SHA-256 manifests and identical shared-core checks.
- Documented local export-mapping gaps, encrypted-input limitation, acceptance trial and private publishing requirement.

## 0.2.0 — Four-sheet analytical report

- Reorganized the Excel report into Dashboard, Expanded analytics, Raw data and Documentation worksheets.
- Combined sleep and behaviour over time on the focused dashboard, with summary numbers and a statistical-analysis panel.
- Added optional dashboard person/admission/unit settings; charts are regenerated by R when input or configuration changes.
- Added configurable individual behaviour flags, their own missingness denominators, and behaviour-specific summaries.
- Added descriptive ward-peer comparisons that exclude the index person across all admissions and require a minimum number of eligible peers.
- Added daily-mean baseline effects and an experimental HAC comparison module. Significance testing is disabled by default because simulation checks exposed poor calibration; opt-in results require methodological review.
- Added a filterable raw-data worksheet containing selected report/baseline source rows, original columns and derived analysis fields. Peer records outside the selected scope are not included in this sheet.
- Expanded the generated demo to eight fictional people in two units over 56 days, with nine separately recorded behaviour types.
- Updated documentation for metric weighting, peer eligibility, data scope and experimental statistical limitations.

## 0.1.0 — Synthetic development preview

- Replaced repeated patient-specific blocks with shared functions for all selected patient admissions and units.
- Added one configuration file for source columns, observation codes, timezone, reporting dates, time bands, baseline, and patient/unit selections.
- Added automatically generated HTML charts and optional Excel reports with chart images. The separate spreadsheet paste step is no longer part of this workflow.
- Added deterministic synthetic observations for six patients across two fictional units.
- Standardized behaviour percentages to explicitly awake checks with known behaviour status; retained missing and conflicting values as unknown.
- Added strict duplicate, header, identifier, timestamp, date-window, and configuration validation.
- Added fixed baseline comparisons and separate pooled-observation and equal-admission unit summaries.
- Made observation proportions the default. Standardized sleep-hours estimates are optional and explicitly labelled as estimates.
- Removed workstation-specific execution, hardcoded credentials, automatic raw-data exports, and dependence on desktop Excel for the core HTML report.
- Added automated regression checks and repeatable synthetic report generation.

Exact chart/formula parity with the former template, local data mapping, expected observation schedules, and clinical validation remain outstanding. Reuse licensing is pending.
